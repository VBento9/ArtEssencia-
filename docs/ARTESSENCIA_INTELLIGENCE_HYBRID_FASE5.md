# Intelligence Hybrid — fase 5: integração de leitura no Stock (branch de desenvolvimento)

Acrescenta um painel no módulo Stock através da camada stock-compact-ui existente, sem modificar index.html, operações de gravação, sincronização ou dados reais. Carrega os motores apenas após pedido. A sessão deve estar desbloqueada, online e com Cloud verificada, sem alterações pendentes, conflito ou sincronização ativa. Verifica getUser e RPC artessencia_is_owner_v1 antes de copiar os campos necessários do runtime local. O relatório não é enviado a serviços externos. O resultado é limpo quando a aplicação bloqueia, fica oculta, perde internet ou o agente é desligado.

Configuração e histórico são voláteis nesta fase. Não é uma consulta direta às tabelas Cloud nem uma política de autorização de servidor para escritas; a verificação do proprietário é uma barreira adicional na interface. O snapshot é uma projeção mínima. Não aplicar nem fundir materiais, nem criar tarefas. A consulta de Cloud usada apenas autentica o proprietário; nenhum novo endpoint pago. Teste do guard: node tests/intelligence-review-guard.test.cjs. Foram exercitadas 15 verificações do guard em JS de autoria; não foram testados navegador, sessão real, service worker ou regressões. A versão e cache de produção não foram alteradas; só alterar quando integrar uma release testada. Não abrir preview com credenciais reais nesta fase.
